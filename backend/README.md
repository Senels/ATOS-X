# ATOS-X Backend

Backend package for ATOS-X, the Binance Global USDⓈ-M Futures trading operating system.

This package contains the API, AI, backtest, dashboard, risk, data and execution layers.

## Development

Install development dependencies from this directory:

```bash
pip install -e ".[dev]"
```

Run tests with:

```bash
pytest -q
```
